## 3. 作成方法

1. `scripts/draw_figures.py` を新設。参考リポジトリと同じ関数構成（`svg / title / box / arrow / note`）と配色定数を使い、Python 標準ライブラリのみで全図を決定論的に生成する。
2. 出力先は `assets/<番号>-<名前>.svg`。幅1000px、最小フォント14px、注記16px（長文は句点で2行に折り返し）、`role="img"` と `aria-label` を付与。
3. `ARTICLE.md` の上記位置に `![alt](assets/xx.svg)` を挿入。alt は参考サイトと同様に図の内容を日本語の文章で書く（キャプション代わり）。
4. 検証：`scripts/check_figures.py` で XML 整形性・最小フォント・viewBox 内収まりを機械確認し、ブラウザ表示で文字の重なりを目視確認する。
5. 完了条件：A の6点（B/C は選択に応じて）が生成・挿入され、Markdown プレビューで本文と図の対応が読めること。
